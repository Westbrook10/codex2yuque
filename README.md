# codex2yuque

[中文版](README_zh.md)

A **zero-dependency** Python tool that converts Markdown math formulas generated by Codex / ChatGPT into formats that Yuque, MarkText, GitHub, and other apps can render correctly.

## What it does

When you generate Markdown documents with math formulas using Codex (or ChatGPT, Claude, etc.), the formulas are written in LaTeX, but with **inconsistent delimiters**:

| Delimiter | Type | Example |
|---|---|---|
| `$$...$$` | Block | `$$f(x)=x^2$$` |
| `$...$` | Inline | `$x$` |
| `\[...\]` | Block (native LaTeX) | `\[\int_a^b f(x)\,dx\]` |
| `\(...\)` | Inline (native LaTeX) | `\(E=mc^2\)` |
| ```` ```math ...``` ```` | Block (code fence) | ```` ```math y = mx + b``` ```` |

Different target apps only recognize a subset:

| Target | Recognized math syntax |
|---|---|
| Yuque (语雀) | Pure LaTeX (no `$`), via "formula card" or "import Markdown" |
| MarkText / Typora | `$$...$$`, `$...$` |
| GitHub | `$$...$$`, `$...$` |

`codex2yuque.py` converts between these syntaxes automatically, saving you from hand-editing delimiters.

## Features

- Recognizes **five** formula delimiter syntaxes (see table above), in a single pass, in document order
- Two output modes:
  - `import`: unify to `$$...$$` / `$...$`, export a .md for Yuque "import Markdown" or MarkText
  - `manual`: replace formulas with `【formulaN】` placeholders + a separate clean LaTeX list, for manual insertion into Yuque "formula cards"
- **Clipboard mode** (Windows): copy → convert → write back to clipboard
- Auto-protects escaped `\$` (a literal dollar sign, not a formula)
- Zero third-party dependencies: file mode uses only the Python standard library; clipboard mode uses Windows built-in ctypes

## Requirements

- **Python 3.6+** (file mode is cross-platform: Windows / macOS / Linux)
- **Windows** (for clipboard mode `--clip`)
- No `pip install` needed; no third-party dependencies

## Usage

### Method 1: Clipboard mode (Windows, simplest)

For pasting AI content into Yuque with manual formula-card insertion:

1. Copy content with formulas in Codex / ChatGPT
2. Double-click `codex2yuque.bat`
3. The body (formulas become `【formulaN】`) is written back to the clipboard; the formula list shows in the console window
4. Paste the body into Yuque, then insert "formula cards" one by one following the list

### Method 2: File conversion (for Yuque "import Markdown" or MarkText)

```bash
python codex2yuque.py input.md -o output.md -m import
```

The exported .md has formulas unified to `$$...$$`, ready for Yuque "import Markdown" or MarkText.

### Method 3: Drag-and-drop conversion (for MarkText)

1. Drag a .md file onto the `convert_md_for_marktext.bat` icon
2. Formulas are converted to MarkText-compatible `$$...$$` (in place)
3. Double-click the .md to view it in MarkText

### Command-line arguments

| Argument | Description |
|---|---|
| `input` | Input .md file (defaults to stdin) |
| `-o, --output` | Output file (defaults to stdout) |
| `-m, --mode` | `import` or `manual` (default `manual`) |
| `--clip` | Read from clipboard, write back after converting |

## FAQ

**Q: Double-clicking the .bat gives "not recognized as an internal or external command"?**
A: Python is not in PATH. Reinstall Python and check "Add Python to PATH", or run `python codex2yuque.py ...` from the command line.

**Q: Formulas still don't render in Yuque?**
A: Yuque doesn't recognize `$...$` / `$$...$$`. Use `manual` mode (clipboard) with "formula cards", or `-m import` with "import Markdown".

**Q: `\[...\]` or ```math doesn't render in MarkText?**
A: MarkText only recognizes `$$...$$`. Use `convert_md_for_marktext.bat` drag-and-drop, or `python codex2yuque.py file.md -m import -o file.md`.

**Q: `\$` in content gets treated as a formula?**
A: No. Escaped `\$` is auto-protected and restored as a literal dollar sign.
